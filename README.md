### [EduCore — Training & Student Management System](https://github.com/omaronline3000/EduCore)

An ASP.NET Core MVC application for managing courses, trainees, instructors, and results.

- Built with **C#, ASP.NET Core MVC, Entity Framework Core, and SQL Server**.
- Implemented authentication and role-based authorization using **ASP.NET Core Identity**.
- Created separate workflows for Admin, Instructor, and Trainee roles.
- Applied Repository and Service layers with Dependency Injection.

**Tech:** `C#` `ASP.NET Core MVC` `EF Core` `SQL Server` `Identity` `LINQ`
